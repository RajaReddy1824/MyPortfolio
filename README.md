# Personal Portfolio Website

A responsive personal portfolio website developed using **HTML5 and CSS3** to showcase my profile, technical skills, educational background, and projects.

### Features
- About Me section with personal and professional details.
- Technical Skills section highlighting my programming skills.
- Education section with interactive flip cards.
- Projects section showcasing my development projects using flip cards.
- Contact section with Email, GitHub, LinkedIn, and Instagram links.
- Smooth navigation and responsive layout.

### Technologies Used
- HTML5
- CSS3
- Font Awesome Icons
